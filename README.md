# Quote Generator

A minimal React web app that generates random quotes. Built with React and Vite, styled with CSS, and hosted on GitHub Pages.

Live Demo: https://clarestar-c.github.io/Quote-Generator/

## Features
* Generates a random quote on click
* Clean, responsive layout
* Fast build powered by Vite

## Tech Stack
* React 19
* Vite
* GitHub Pages

## Run Locally
```bash
npm install
npm run dev
